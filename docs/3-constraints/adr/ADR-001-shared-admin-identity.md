# ADR-001: 管理员与决策者复用 admins 身份来源

**日期**：2026-09-09  
**状态**：已接受

## 背景

NEPM 系统管理员和 NEPV 决策者都属于员工端身份。数据库已有 `admins` 表，但没有独立决策者账号表。为 NEPV 新建平行账号表会复制账号、密码和后续 HR 同步逻辑。

## 决策

NEPM 与 NEPV 均使用 `admins.admin_code` 加密码登录。`admins.role_code` 显式保存 `NEPM_ADMIN` 或 `NEPV_DECISION_MAKER`；认证请求必须与角色匹配。NEPG 保持使用 `grid_member.gm_code`，不与管理员账号混用。

密码字段扩容为 PBKDF2 所需长度；不插入默认账号、密码或角色。登录成功仅建立最小 HTTP Session，业务页面授权留待后续任务。

## 后果

- 管理员和决策者认证服务、密码迁移和未来 HR 集成只维护一套身份来源。
- 配置管理员账号时必须显式维护 `role_code`；空角色或错误角色无法登录任何员工端。
- NEPV 当前仅拥有最小登录落地页，统计大屏和业务权限须由后续任务实现。
