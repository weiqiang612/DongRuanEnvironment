# 项目说明

## 项目目标

该项目实现东软环保公众监督系统的最小可用切片：公众提交 AQI 反馈，管理员查看和维护反馈，页面可按省、市筛选区域。

## 当前范围

- 后端提供 AQI 反馈的查询、详情、保存、更新、删除，以及省市选项查询。
- 前端提供反馈列表与表单页面，并通过 Vite 代理访问后端。
- MySQL 数据库名配置为 `nepmdb`，包含 `aqi_feedback`、`grid_province`、`grid_city` 等表。

## 非目标

当前代码未实现完整登录、角色权限、网格员指派或统计决策流程；新增这些能力前需创建任务并明确接口、表结构和验收标准。
