# 项目说明

## 文档依据与范围说明

本项目的目标业务来自《东软环保公众监督系统-需求分析文档》和《东软环保公众监督系统-软件概要设计报告》（均为 2026-08-30 版本）。两份文档定义的是完整业务目标；本仓库当前仅落地其中的 AQI 公众反馈最小切片。本文档及 `docs/2-designs/` 会分别标明“已实现基线”和“目标设计”，不得将目标设计表述为已交付功能。

## 业务目标

建立环保公众监督平台，汇总不同地区的空气质量反馈，由管理员指派 AQI 检测网格员实地检测，形成可追溯的 AQI 结果、预警与统计数据，为环保决策提供依据。地区按省、市及后续最小网格单元管理，优先覆盖省会和大城市。

## 目标使用端

| 端 | 使用者 | 主要职责 |
|---|---|---|
| NEPS | 公众监督员 | 注册登录、提交反馈、查看本人处理进度与检测结果 |
| NEPG | AQI 检测网格员 | 接收任务、实测 SO₂/CO/PM2.5、提交检测结果 |
| NEPM | 系统管理员 | 查询反馈、按本地优先原则指派或重派任务、查看预警和统计 |
| NEPV | 决策者 | 通过统计页面或可视化大屏查看统计与高等级预警 |

## 当前已实现基线

- 后端已提供四端认证登录及 Session 校验能力（NEPS、NEPG、NEPM、NEPV），以及省、市选项查询。
- 公众监督员端（NEPS）：提供反馈列表、详情、提交、待指派反馈更新与删除。
- 管理者端调度（TASK-007）：提供反馈多维查询、详情、指派日志追溯、本地候选网格员查询（同城优先、同省兜底）、指派/重派调度以及超时反馈统计概览。
- 网格员端检测（TASK-008）：提供已指派/已完成任务列表与详情查询，支持实测 SO₂、CO、PM2.5 浓度提交，由服务端自动根据 AQI 字典计算各分项等级与系统最终 AQI，并在同一事务内完成任务流转与 4~6 级高等级预警记录生成。

## 当前任务与范围边界

### TASK-009 范围（NEPM 管理者端检测处置与运营统计）
- **检测结果只读查询**：支持多维度条件（省市、最终 AQI 等级、提交时间区间、关键词、分页）查询网格员实测数据，包含三项实测数值及分项等级、系统最终 AQI 等；支持单条检测结果详情查看。
- **AQI 预警原子处置**：支持查询 4~6 级高等级预警列表（按处置状态 PENDING/HANDLED、省市过滤与分页）；支持对处于 PENDING 状态的预警执行原子处置（更新为 HANDLED 并记录处置时间 `handled_at`），采用状态原子条件更新杜绝并发冲突与重复处置（冲突返回 HTTP 409）。
- **超时任务调度复用**：无缝复用 TASK-007 沉淀的反馈超时识别与调度指派链路，保持任务调度的一致性。
- **综合运营统计聚合**：基于实测结果与反馈数据，提供按省市、提交时间区间的综合运营统计，包括完成检测总数、1~6 级 AQI 等级分布、月度趋势、高等级预警统计（总数、待处置数、已处置数）。

### TASK-010 边界与当前非目标
- **NEPV 决策者端**：面向决策者的大屏数据可视化、决策分析报表、网格覆盖率深度多维聚合等功能属于 TASK-010 范围，非 TASK-009 范围。
- **外部系统集成**：东软 HR 系统实时人事状态同步接口、移动端适配、OAuth2/JWT 改造暂不在本期交付范围。
