# 项目说明

## 文档依据与范围说明

本项目的目标业务来自《东软环保公众监督系统-需求分析文档》和《东软环保公众监督系统-软件概要设计报告》（均为 2026-08-30 版本）。两份文档定义的是完整业务目标；本仓库当前仅落地其中的 AQI 公众反馈最小切片。本文档及 `docs/2-designs/` 会分别标明“已实现基线”和“目标设计”，不得将目标设计表述为已交付功能。

## 业务目标

建立环保公众监督平台，汇总不同地区的空气质量反馈，由管理员指派 AQI 检测网格员实地检测，形成可追溯的 AQI 结果、预警与统计数据，为环保决策提供依据。地区按省、市及后续最小网格单元管理，优先覆盖省会和大城市。

## 目标使用端

| 端 | 使用者 | 主要职责 |
|---|---|---|
| NEPS | 公众监督员 | 注册登录、提交反馈、查看本人处理进度与检测结果 |
| NEPG | AQI 检测网格员 | 接收任务、实测 SO₂/CO/PM2.5、提交检测结果 |
| NEPM | 系统管理员 | 查询反馈、按本地优先原则指派或重派任务、查看预警和统计 |
| NEPV | 决策者 | 通过统计页面或可视化大屏查看统计与高等级预警 |

## 当前已实现基线

- 后端已提供 AQI 反馈的查询、详情、保存、更新、删除，以及省、市选项查询。
- 前端已提供反馈列表和编辑表单，并通过 Vite 代理访问后端。
- 当前数据基线为 `aqi_feedback`、`grid_province`、`grid_city` 等表；公众登录后可提交和查看本人反馈，且仅待指派反馈可由归属人维护，但未覆盖完整目标数据模型。

## 当前非目标

当前已实现四端 PC 登录入口：NEPS 使用 `supervisor.tel_id`；NEPG 使用 `grid_member.gm_code`；NEPM 与 NEPV 使用 `admins.admin_code`，并以 `role_code` 区分管理与决策身份。NEPS 登录后可在公众工作台提交、查看和维护本人待指派反馈，并可从“欢迎您”账户菜单退出登录；员工端登录后只进入最小落地页，未开放实际业务模块。注册及 HR 集成仍未实现。任务指派、实测 AQI、预警、超时处置、统计和决策大屏同样尚未实现；每项能力进入开发前须创建任务，并明确接口、数据库迁移、权限、验收标准和回滚方案。
