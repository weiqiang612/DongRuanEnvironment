# 需求分析

## 核心业务链路

公众监督员选择省、市并填写具体地址、预估 AQI 等级和空气质量描述后提交反馈；管理员查询并将反馈优先指派给本地可工作网格员，缺少本地候选人时按就近原则异地指派；网格员提交 SO₂、CO、PM2.5 实测浓度；系统以三项对应 AQI 等级的最大值作为最终 AQI，完成任务、生成预警和统计；公众、管理员与决策者按角色查看相应结果。

## 功能需求

| 编号 | 角色 | 需求 |
|---|---|---|
| R-01 | 公众监督员 | 注册和登录；手机号为唯一登录标识；提交反馈时选择省、市，填写具体地址、预估 AQI 和描述。 |
| R-02 | 公众监督员 | 查看本人历史反馈，以及待指派、已指派、已完成、已超时的处理进度；已完成时查看最终 AQI、三项实测值和检测时间。 |
| R-03 | 网格员 | 查看分配给本人的任务及详情；输入三项实测浓度并提交检测结果。 |
| R-04 | 系统管理员 | 按省、市、状态、超时标识、提交时间和关键词查询反馈；对待指派反馈首次指派，对已指派或已超时反馈重派或继续处理。候选人仅限本地可工作网格员，先同城市、后同省其他城市；网格员和管理员由东软 HR 系统管理，不自行注册。 |
| R-05 | 系统管理员 | 查看超时任务和调度运营概览；待指派超过 2 小时，或已指派超过 24 小时未完成时标记超时。检测结果确认、AQI 预警处置和完整统计在网格员端产生真实检测数据后实施。 |
| R-06 | 系统管理员、决策者 | 按省、AQI 等级、月份、检测数量和网格覆盖率查看统计；决策者可在可视化大屏查看统计与预警。 |

## 当前登录范围

PC 端统一入口开放四端登录：NEPS 使用 `supervisor.tel_id` 与密码；NEPG 使用 `grid_member.gm_code` 与密码；NEPM、NEPV 使用 `admins.admin_code` 与密码。管理员必须具有精确的 `NEPM_ADMIN` 或 `NEPV_DECISION_MAKER` 角色才可进入对应端，角色为空或不匹配时按认证失败处理。NEPG 员工登录成功进入任务列表，仅能访问本人已指派或已完成任务；NEPM、NEPV 仍按各自已实现范围进入工作台或确认页。

注册、找回密码、移动端、全局角色拦截和公众反馈归属隔离均不在本期范围。NEPS 公众端提供当前 Session 的退出登录；不得创建默认员工账号、密码或角色；历史明文密码只在本人首次成功认证后原位升级为 PBKDF2 哈希。

## 业务规则

- AQI 等级为 1 至 6；最终等级取 SO₂、CO、PM2.5 三项对应等级的最大值。
- 最终 AQI 达到 4 级（中度污染）及以上时生成高等级预警。
- 公众只能访问本人反馈；员工端按角色授权。关键写操作需记录操作人和时间。
- NEPG 仅提交 SO₂、CO、PM2.5 非负浓度；服务端按 `aqi` 字典唯一匹配三项等级、取最大值为最终 AQI，并在一个事务内写入检测结果、完成任务和条件性预警。已完成或竞争失败的任务不得重复提交。
- 统计只以有效完成的检测结果为统一口径。
- 管理端首次指派、重派和继续处理必须同时更新任务事实与操作日志；操作人从 NEPM Session 解析，前端不得提交或覆盖操作人、状态、超时标识和日志。
- 本地 `grid_member.state = 0` 是 TASK-007 的唯一可工作依据；候选顺序固定为同城市优先、同省其他城市兜底，同省无候选人时不可指派。东软 HR 实时工作状态查询留待独立集成任务。

## 非功能需求

- 常用查询响应时间不大于 5 秒，目标支持 7×24 小时运行。
- 页面应清晰展示状态、查询条件和可理解的错误提示；浏览器兼容 Windows、Linux 环境下的主流 Chrome、Firefox。
- 服务端负责认证、权限、参数和浓度范围校验，客户端不得计算或保存可篡改的最终 AQI。
- 登录密码不得以明文形式新建或返回。历史 `supervisor.password` 首次验证成功后须立即升级为 PBKDF2 哈希；密码错误和未知手机号对外返回相同的认证失败结果。
- 关键操作应具备日志、事务与可追溯能力；错误响应不得泄露内部实现或敏感信息。

## 当前实现边界与待澄清事项

当前实现已覆盖四端登录和 NEPS 反馈提交、本人历史查询与基础状态展示：服务端从 Session 取得反馈归属，且只有本人待指派反馈可编辑或删除。TASK-007 将补齐 NEPM 的反馈管理、任务调度、超时预警和运营概览；网格员检测、最终 AQI、AQI 预警处置和完整统计仍未实现。现有删除接口仍使用 `GET`，未来改为 `DELETE` 前需评估前端兼容性。认证方式、HR 接口协议、统计指标精确定义和历史数据迁移策略，均须在对应功能任务中先确认。
